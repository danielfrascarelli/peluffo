# 0006 Node 24

Date: 2026-10-20 · Status: accepted · Supersedes the Node line of [0004](0004-toolchain-pins.md)

## Context

Node 24 is the active LTS and the default on the development machine. Running Node 22 meant switching versions before every pnpm command.

## Decision

Node 24 in `.nvmrc`, `engines.node` and CI (which reads `.nvmrc`). `@types/node` follows the runtime major.

## Alternatives rejected

- Stay on Node 22: still supported, but every shell needed `nvm use` to avoid the engine warning.

## Consequences

- Machines without Node 24 need `nvm install`.
